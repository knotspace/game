# 青の分岐点

選択によって人生が分岐する、日本の人生シミュレーションです。出生証明書を発行して人生を開始し、学校・進路・仕事・人間関係・日々の出来事を選びながら、自分だけの物語を進めます。

## 主な機能

- 開始ごとに名前・出生地・家族構成・性格傾向をランダム生成
- 出生証明書を確認してから人生を開始する演出
- 12種類の出来事テーマと25種類の情景文を組み合わせた300通りのイベント表現
- 15歳・18歳の進路選択、23歳の働き方の選択
- 健康・知識・幸福・人間関係・能力・資産の6つのステータス
- 35歳以降は5年単位で進行を早める
- ブラウザ内への自動保存と、再訪時の続きから再開
- スマートフォン・PWA対応

## 公開

GitHub Pages: Settings → Pages → Branch `main` / folder `/(root)`。

## データについて

氏名・出生地・家族構成・出来事はゲーム用の架空データです。現実の個人を再現するものではありません。ステータス変化や出来事の発生はゲーム上の演出であり、実際の人生の確率・収入・進路結果を予測するものではありません。

## 操作

選択肢を選ぶとステータスと人生の記録に反映されます。画面を閉じても進行状況は同じブラウザ内に保存されます。別の人生を始める場合は「最初から」を選択してください。
